Dés

Écris la formule. Appuie sur Tirer. La ligne verte est déjà copiée.

Tu écris la formule, rien d’autre. Un seul groupe de dés, puis un bonus. Exemples : 1d20+24, 1d8+22, 2d6+10, 3d8-2, 4d6, 1d100.

Le gros chiffre est le total. La ligne verte est déjà copiée : colle-la dans le chat.

Brut, c’est seulement la face du dé. Le + ou le − n’y entre pas.

1d20+2d6 est refusé. Un mauvais texte ne change pas le dernier jet.

Un autre jet : change la formule, puis Tirer. Un deuxième clic relance.
